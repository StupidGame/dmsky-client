## Aria との完全な機能一致に向けた残作業

この版で「Aria・Miria の全機能を搭載済み」とは表記しません。
少なくとも以下は未実装、または追加の個別検証が必要です。

- Aria 固有の AiScript 実行環境・Play のアプリ内実行／作成／編集・プラグイン互換。Play の一覧表示は対応済み。
- Aria のギャラリー専用画面・編集、予約投稿、スクラッチパッド、QR 読み取り、アバターデコレーションの全操作。
- Aria と同等の独立したドライブ管理画面。現状は投稿からのドライブ選択・アップロードが中心。
- APNs・FCM・UnifiedPush による、アプリ終了中のプッシュ通知。
- Aria 独自の設定・タブ操作・メディア処理すべてとの厳密な一致。
- iOS 共有拡張の組み込みと App Group の署名・配布設定。
- 各 OS のアクセシビリティ・大きい文字・実機での長時間接続。
- フォーク独自 API やサーバー固有の非標準機能。

## Web

Web ビルドを追加しています。ネイティブのウィンドウ管理・共有受信・App Group はブラウザーでは呼びません。
投稿・チャットの添付はブラウザーで選択したファイルのバイト列を扱い、保存はファイルピッカーを使用します。
HTTPS・CORS・メディア形式などのブラウザー制約があります。
OS 連携プラグインを使う全機能の Web 互換が完了したと見なさないでください。
