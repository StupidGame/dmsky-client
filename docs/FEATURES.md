# 機能対応表

DMSKY Client は既存の Misskey クライアント機能を基盤に、独自の設計・操作性・保守性を優先して開発します。他クライアントとの完全一致は目標にしません。

| 分類 | 機能 | 状況 |
| --- | --- | --- |
| 認証 | MiAuth・API キー・複数サーバー・複数アカウント | 実装あり |
| TL | ホーム・ローカル・ソーシャル・グローバル、リスト・アンテナ・チャンネル・ロール | 実装あり。サーバー設定に依存 |
| 表示 | タブ編集・並べ替え・スワイプ・複数列デッキ | 実装あり |
| 投稿 | 本文・返信・Renote・引用・公開範囲・CW・添付・画像編集・投票 | 実装あり。形式・OSによる差あり |
| 本文・メディア | MFM・カスタム絵文字・リンク・コード・画像・動画・音声 | 実装あり。環境による差あり |
| リアクション | ピッカー・履歴・デッキ・取り消し | 実装あり |
| 通知 | アプリ内通知一覧・ノートやユーザーへの移動 | 実装あり |
| 通知 | バックグラウンド／終了中のプッシュ通知 | **未完了・リリース必須**。Issue #3 で管理 |

| チャンネル・検索 | チャンネル、ノート・ユーザー・ハッシュタグ検索 | 実装あり。全文検索はサーバー依存 |
| ユーザー | プロフィール・フォロー関係・編集 | 実装あり |
| ミュート等 | ユーザー・単語・リアクション・インスタンス、ブロック・通報 | 実装あり |
| 発見 | みつける・連合・お知らせ・サーバー情報 | 実装あり |

| 外観 | DMSKY ライト・ダーク、銀枠、青いパネル、金色の選択 | 追加実装 |

## リリース必須条件

- プッシュ通知は必須。アプリ内通知一覧や WebSocket 受信だけでは完了としません。
- Android の FCM／UnifiedPush、iOS の APNs、Web Push で、アプリ終了中の受信を実機確認します。
- 通知タップ遷移、アカウント別端末登録・解除、トークン更新、権限拒否・再登録を検証します。
- 配信基盤・認証情報など外部条件が未整備の場合は未完了として扱い、完成・マージ可能とは表示しません。
- 秘密鍵・証明書・サービスアカウント等の秘密情報はリポジトリへコミットしません。

## Web

Web ビルドを追加しています。ネイティブのウィンドウ管理はブラウザーでは呼びません。投稿・チャットの添付はブラウザーで選択したファイルのバイト列を扱い、保存はファイルピッカーを使用します。HTTPS・CORS・メディア形式などのブラウザー制約があります。
